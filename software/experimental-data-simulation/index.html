Web application for the simulation of experimental data

Web application
Bernabeu, P., & Lynott, D. (2020) web application, research and teaching applications, R
Code DOI GitHub repository Web application

Abstract

This open-source, R-based web application is suitable for teaching and research in the experimental sciences. It creates varied data sets with specified structures, such as between-group or within-participant variables that can be categorical or continuous. These features are set across the tabs of the app. In the penultimate tab, users can build a custom summary of the current data set, and in the last tab they can download the data set along with the list of parameters.

  Purposes

This open-source, R-based web application is suitable for teaching and research in the experimental and quantitative sciences. It creates varied data sets with specified structures, such as between-group and within-participant variables that can be categorical or continuous. The parameters are set in the tabs (sections) of the top menu, and the data set can be downloaded from the last tab. The application saves time and offers flexible control over the parameters.

Guidelines

General guidelines include the following:

  • In the names of variables, it is best to use only alphanumeric characters and underscores, which can separate words (e.g., variable_name). Each variable needs a different name.

  • In the levels of categorical variables, alphanumeric characters, special characters and spaces are allowed.

  • In numeric fields (e.g., ‘Mean’, ‘Standard deviation’, ‘Relative probability [0, 1]’), only numbers and decimal points are allowed.

  • As the data set grows, so does the processing time.

More specific guidelines are available in each tab.

Code

This web application was developed in R (R Core Team, 2020). The code is available on GitHub, where contributions are welcome. A copy is archived on Zenodo (Bernabeu & Lynott, 2024). The initial code drew on Section 5.7 (‘Simulating Data for Multi-Factor Designs’) of Crump (2017). The R packages used include dplyr (Wickham et al., 2020), DT (Xie et al., 2020), flexdashboard (Iannone et al., 2020), shiny (Chang et al., 2020) and stringr (Wickham, 2019).

Options for Development and Local Use of the App

Option A) Using Local R/RStudio or Posit Cloud Project or Binder RStudio Environment

  1. [Only needed in local R/RStudio] Install the package versions used in the latest release of this application by running:

    install.packages('devtools')
library(devtools)
install_version('dplyr', '1.0.2', 'https://cloud.r-project.org')
install_version('DT', '0.15', 'https://cloud.r-project.org')
install_version('flexdashboard', '0.5.2', 'https://cloud.r-project.org')
install_version('htmltools', '0.5.0', 'https://cloud.r-project.org')
install_version('knitr', '1.30', 'https://cloud.r-project.org')
install_version('ngram', '3.0.4', 'https://cloud.r-project.org')
install_version('purrr', '0.3.4', 'https://cloud.r-project.org')
install_version('shiny', '1.5.0', 'https://cloud.r-project.org')
install_version('stringr', '1.4.0', 'https://cloud.r-project.org')
install_version('tidyr', '1.1.2', 'https://cloud.r-project.org')

  2. Open the index.Rmd script.

  3. Run the application by clicking ▶️ Run Document at the top left or by running rmarkdown::run('index.Rmd') in the console.

  4. Click Open in Browser at the top left.

Option B) Using Dockerfile

The README of the GitHub repository explains how to build and run the app with the Dockerfile.
