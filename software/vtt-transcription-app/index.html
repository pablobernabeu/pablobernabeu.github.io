WebVTT caption transcription app

Web application
2021 research and teaching applications, web application, R
Code DOI GitHub repository Web application

Abstract

This open-source, R-based web application converts video captions (subtitles) from the Web Video Text Tracks (WebVTT) Format into plain text. Users upload a WebVTT file with the extension .vtt or .txt, and the application automatically removes metadata such as timestamps and formats the text.

The application accepts caption files in the Web Video Text Tracks (WebVTT) Format with the extension .vtt or .txt, such as this example or this one.

Download VTT file

Once a caption file is uploaded, the application removes metadata such as timestamps and formats the text into a paragraph. The result is displayed on the page and can be downloaded as a .docx or .txt document. In this way, the application makes the content of video captions more accessible. The uploaded data are available only to the user and are deleted when the page is closed.

Programming Details

The source code is available on GitHub under a Creative Commons Attribution 4.0 International licence, and the app can be extended through pull requests. The code is also archived on Zenodo (Bernabeu, 2024). Questions and suggestions can be submitted as issues or emailed to pcbernabeu@gmail.com.

The core of the application is the index.Rmd script, which processes the VTT file with regular expressions.
